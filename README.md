# Weather Dashboard

  ![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)

  ## Description
  ```
  It will display weather information for a number of cities.
  ```

  ## Installation
  ```
  npm i
  ```

  ## Usage
  ```
  You can search a city in the search bar and the weather information for that city will show.
  ```

  ## Contribution
  ```
  Add more detailed information or maps showing precipitation.
  ```

  ## Tests
  ```
  Try to see what cities are available and see how many cities can be saved to the search history.
  ```
